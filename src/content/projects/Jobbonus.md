# Jobbonus

## Overview

The Jobbonus is a yearly, tax-free premium of up to €600 for employees and civil servants in Flanders with lower wages. This initiative aims to make work financially more attractive than unemployment and to support purchasing power, with automatic payment for most workers under set income thresholds.

## Key Features

- **Tax-free premium** up to €600 annually
- **Automatic payment system** for eligible workers
- **Income threshold-based** eligibility criteria
- **Work incentive program** promoting employment over unemployment

## Impact

This project supports the Flemish government's goal of encouraging employment while providing financial relief to lower-income workers, making work more financially attractive and supporting overall purchasing power in the region.

## Technologies Used

- Government payment systems
- Automated eligibility verification
- Secure financial processing platforms
