# Loket

## Overview

Loket serves as the central gateway application for all services and interactions related to the Flemish Department of Work, Economy, Science, Innovation and Social Economy (WEWIS). This comprehensive platform provides unified access to various departmental services and applications.

## Key Features

- **Central gateway**: Single entry point for departmental services
- **Service integration**: Connects multiple government applications
- **User authentication**: Secure access management across services
- **Service discovery**: Easy navigation to relevant applications
- **Unified experience**: Consistent interface across departmental tools

## Impact

This platform streamlines citizen and business interactions with the department, reducing complexity and improving accessibility to government services while maintaining high security standards.

## Technologies Used

- Government portal architecture
- Single sign-on (SSO) systems
- Service integration frameworks
- User authentication platforms

## My Role

I was responsible for testing the integration points between various departmental applications and ensuring seamless user experiences across the unified platform, focusing on authentication flows and service accessibility.
