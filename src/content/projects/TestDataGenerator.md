# Test Data Generator

## Overview

The Test Data Generator is an open-source, serverless tool designed for generating high-quality synthetic test data. This project, developed while at b.ignited, provides developers and testers with a flexible, scalable solution for creating realistic test datasets without compromising sensitive information.

## Key Features

- **Serverless architecture**: Cost-effective, scalable data generation
- **Synthetic data generation**: Realistic data without privacy concerns
- **Open source**: Free and community-driven development
- **Multiple data types**: Support for various data formats and structures
- **Customizable templates**: Configurable data generation patterns
- **API-first design**: Easy integration with existing testing workflows

## Impact

This tool democratizes access to high-quality test data generation, enabling teams to improve their testing practices while maintaining data privacy and reducing costs associated with test data management.

## Technologies Used

- Serverless computing platforms
- Data generation algorithms
- API development frameworks
- Open source development practices
- Cloud infrastructure services

## My Role

As a key contributor to this project, I was responsible for designing the data generation algorithms, implementing quality assurance processes, and ensuring the tool met the diverse needs of development and testing teams across various industries.
