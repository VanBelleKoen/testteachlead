# Sustatool

## Overview

Sustatool is an innovative application that guides users through a comprehensive five-phase process—from analysis to action and reporting—across 14–15 key themes aligned with the United Nations Sustainable Development Goals (SDGs). It offers concrete initiatives and customizable KPIs for measurable impact.

## Key Features

- **Five-phase guided process**: Analysis → Planning → Implementation → Monitoring → Reporting
- **SDG-aligned themes**: 14–15 key sustainability themes
- **Customizable KPIs**: Tailored metrics for measuring impact
- **Concrete initiatives**: Actionable steps for sustainability improvement
- **Progress tracking**: Built-in monitoring and reporting capabilities

## Impact

This tool empowers organizations to systematically approach sustainability, providing structured guidance and measurable outcomes aligned with global sustainability goals.

## Technologies Used

- Web-based application platform
- Data analytics and KPI tracking
- Interactive user interface
- Reporting and visualization tools
